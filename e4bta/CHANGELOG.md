# e4BTA Changelog

## 0.6.0

- Added a native e4BTA page to BTA's in-game Options menu.
- Added settings for automatic hosting, the default host port, lobby access, and whether e4BTA should start Steam when needed.
- Added a shared options-page API so addons can place their controls alongside e4BTA's controls.
- Added first-class e4BTA Voice integration; when the addon is installed, its toggle and hotkeys appear on the e4BTA page.
- Added reusable Steam Voice and addon-channel support for companion mods.
- Added the Steam Friends icon to the e4BTA options page and placed the page with the other mod settings.
- Registered e4BTA language resources through HalpLibe so option names render correctly.
- Fixed stale guidebook menus interfering with later inventory clicks and block interactions.

## 0.4.0

- Initial public BTA release of the Steam multiplayer tunnel.
