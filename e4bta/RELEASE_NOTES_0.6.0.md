e4BTA 0.6.0 adds a proper in-game configuration page and first-class support for the optional e4BTA Voice addon.

Changes since 0.4.0:

- Configure automatic hosting, host port, lobby access, and Steam auto-start from BTA's Options menu.
- Disable automatic Steam launching while keeping it enabled by default for existing behavior.
- Use one shared e4BTA settings page for the base mod and installed addons.
- Expose Steam Voice and addon-channel support used by e4BTA Voice.
- Display translated setting names and the Steam Friends icon in the options list.
- Fix stale guidebook menus interfering with later inventory and block interactions.

Requires Better Than Adventure 8.0.1, Fabric Loader 0.18.4-bta.11, and HalpLibe 6.1.4 or newer.
